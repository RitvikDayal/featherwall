FeatherWall

Live wallpapers for Windows that don't eat your laptop.

Download for Windows View the source

7 MB · Windows 10 1809 or newer · needs the .NET 10 desktop runtime

It's one process

Most wallpaper engines want several processes, a launcher, an account, and an embedded browser to loop an MP4. FeatherWall is featherwall.exe and nothing else, built on Win32, Direct3D 11 and DirectComposition.

It also renders on the Windows 11 24H2 desktop, which changed how the shell composes wallpapers and left a lot of older tools drawing a black rectangle. FeatherWall detects both the classic and the newer layout at startup.

What it costs you

Measured over sampled 30 to 40 second windows on a running instance, not estimated. Windows 11 Pro 26200, 24 logical cores, 2560×1600 at 150% scaling.

A still wallpaper is drawn once and then costs nothing: no timers, no frames, no GPU work. Video stops rather than throttles when a fullscreen app is in front, the session locks, you connect over remote desktop, or battery saver switches on.

The clock takes any font you own

Nine positions, any installed typeface, any size and colour, optional seconds and date. The settings panel previews it with the same renderer that paints your desktop, so what you see while choosing is what you get.

Wallpapers shown come from the built-in gallery: public domain and CC0 media from NASA and Wikimedia Commons, downloaded from the source with no API key and no tracking.

Before you download

Releases are unsigned, so SmartScreen will warn you. That is worth taking seriously rather than clicking through on trust: verify the archive, or build it yourself from source.

Things that have not been tested

Multi-monitor layouts, the pre-24H2 desktop layout, and recovery after Explorer restarts are written and unit-tested, but have never run on hardware. There is one developer and one display. If you have a second monitor, saying what happens is the most useful thing you could do for this project.
