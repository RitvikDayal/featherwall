01Composition

Inside the stack, not on top of it

Most wallpaper tools park a borderless window behind your icons and hope nothing notices. FeatherWall inserts a real visual into the desktop's own composition tree, which is why your icons, your right-click menu and your window ordering all keep behaving normally.

24H2 changed the rules

Windows 11 24H2 raised the desktop out of reach of the old WorkerW child-window trick, which is why a lot of wallpaper tools started rendering a black screen. FeatherWall detects the topology at runtime and handles both layouts.

One process, no shell

Direct3D 11 and DirectComposition, called from C# through Vortice. There is no Chromium, no Electron and no separate launcher sitting in the background.

It gets out of the way

Playback stops rather than throttles for fullscreen apps, the lock screen, remote sessions and battery saver. A game never competes with your wallpaper for the GPU.

All of this lands on the integrated GPU. nvidia-smi lists no FeatherWall process on the RTX 5090, which stayed at 0% throughout. The compositor lives on whichever adapter drives your display, so the wallpaper never competes with a game on the discrete card.

Two things the numbers do not say on their own. GPU percentages are per engine and do not sum, which is why the table shows the busiest one, the same as Task Manager. And graphics memory is a separate allocation from the working set, so the honest total for a wallpaper is the working set plus both graphics figures. Paused is the largest memory row because buffers are retained so resuming is instant, while CPU and the video engines drop to nothing.

Two corrections this page owes you. It used to say dedicated VRAM reads 0 MB “because integrated graphics borrow system RAM”. That is wrong: this machine's integrated Arc reports 2048 MB of adapter RAM and Windows attributes 232 MB of dedicated usage to FeatherWall on it. The old explanation made the footprint look smaller than it is. It also published 0.004% CPU for the paused state; the harness measures 0.034%. Both numbers here now come from the script rather than from reading Task Manager, and the correction goes against us on the paused row.

1080p60 has never been measured, so its tab shows dashes rather than a number. An empty cell means nobody has run it — not zero, and not unknown-but-probably-fine. CPU also moves two- to threefold between runs of the same clip on the same machine, so treat any single figure as one sample.

What the widgets cost. Measured across two runs in one session. On a still image the widgets take CPU from 0.026% to 0.135% of the machine — about a thirtieth of one core, but roughly five times the baseline, because a still wallpaper previously did nothing at all after first paint. That is the record's frame clock, and switching off “spin while playing” gives it back. On a 4K60 video the same widgets move CPU from 0.721% to 0.988% and the GPU not at all, because the decoder already dominates.

03The widgets

A clock, a charge, a record

The clock takes any typeface you own, at any of nine positions, with adjustable size, colour and opacity — previewed in the settings panel by the same renderer that paints your desktop. Alongside it: a battery halo whose ring is the charge and whose colour steps with it, and a record that shows what you are listening to, with the real album artwork on its label, turning while the music plays.

The record is the only part that runs on a frame clock, and it stops the moment anything covers the desktop, the display sleeps, or the music does. Turning off “spin while playing” removes the timer entirely and leaves the artwork and the progress ring as a still image. Everything else repaints only when Windows pushes an event — a battery percentage moving, a track changing.

04Install

Get it, check it, or build it

Releases are unsigned, so SmartScreen will warn you the first time. Verify the archive against the published hash, or skip the binary entirely and build it yourself.

Download Fastest

Unzip anywhere and run FeatherWall.exe. It lives in the tray.

Get the ZIP 7.2 MB

Verify Then

Check what you downloaded before you run it. PowerShell, no extra tools.

Get-FileHash .\featherwall-v0.2.0-win-x64.zip ` -Algorithm SHA256

Should match the hash on the left, character for character.

Build it Or, instead

Needs the .NET 10 SDK. About a minute on a cold clone.

git clone https://github.com/RitvikDayal/featherwall cd featherwall dotnet publish src/FeatherWall -c Release

Run dotnet test first if you want to check the suite yourself.

A winget package is submitted and waiting on review at microsoft/winget-pkgs#417753. Until a maintainer merges it, winget install FeatherWall will not find anything, so it is not listed above.
